## Версия 1.33.0 - 23 июня 2026

### Функции
- **Supply Depot — Custom Apps**: Новый дом для устанавливаемых приложений в NOMAD, позволяющий запускать *свои* пользовательские Docker-контейнеры — не только отобранный каталог. Укажите образ, отображения портов, привязки томов, переменные среды и ограничения памяти/CPU, и NOMAD запустит его как управляемый контейнер-брату. Проверка предварительная с задержкой в реальном времени предупреждает о конфликтах портов и ограничениях ресурсов при вводе, блокируя небезопасные конфигурации, с возможностью "установить в любом случае" для предупреждений (например, недоверенный реестр или тег `:latest`). Установленные пользовательские приложения можно редактировать, обновлять (повторно извлечь последнюю версию и пересоздать с безопасным откатом, если новый контейнер не запустится) и удалять (опционально удалив образ), а каждый установленный приложение — отобранное или пользовательское — получает модальные окна **Logs** и **Stats**. Привязки к путям хоста укреплены против утечек, а журналы и статистика ограничены только контейнерами, управляемыми NOMAD. Благодарность @jakeaturner за вклад!
- **Supply Depot — Onboarding and Fixes for Curated Apps**: Каждое отобранное приложение теперь поставляется с документацией по началу работы, специфичной для NOMAD (первый запуск, учетные данные по умолчанию, расположение данных, что работает и что не работает оффлайн), глубоко связанное с карточкой через пункт **Manage › Docs**. Кроме того, есть набор исправлений установки, чтобы девять документированных приложений — Stirling PDF, File Browser, Calibre-Web, IT Tools, Excalidraw, Homebox, Vaultwarden, Jellyfin, Meshtastic Web — работали "из коробки": за seeded учетные данные вместо случайных паролей, встроенная библиотека Calibre, HTTPS по умолчанию там, где приложение требует безопасного контекста (Vaultwarden), исправленные внутренние порты (Meshtastic Web), предварительно созданные папки media (Jellyfin) и переход на поддерживаемую версию образа (Homebox). Теперь вы также можете **редактировать отобранные приложения**, а не только пользовательские — изменения объединяются с существующей конфигурацией приложения (сохраняя продвинутые настройки, такие как запросы к устройству GPU), и приложение помечается, чтобы сейдер не перезаписывал его, в то время как неподправленные приложения продолжают получать обновления каталога. Благодарность @chriscrosstalk за вклад!

### Исправления ошибок
- **Storage**: при переносе администраторского тома на другой диск дочерние приложения (Kiwix, Ollama, Qdrant, Flatnotes, Kolibri) теперь автоматически следуют за новым расположением вместо монтирования старого пустого пути. Корень хост-строки теперь определяется из фактического монтирования администратора, с явным переопределением `NOMAD_STORAGE_PATH` и более понятными комментариями в compose.
- **System**: сбой установки сервиса теперь откатывается к предыдущему контейнеру, если новый не запустится, поэтому сервис остаётся в работе на старой версии вместо того, чтобы быть отключенным. Также очищается любая устаревшая оставшаяся контейнера, чтобы повторная попытка не застревала бесконечно. Благодарность @chriscrosstalk за вклад!
- **System**: сбои установки сервиса из-за конфликта порта на хосте (часто из-за существующей установки Ollama на порту 11434) теперь показывают понятное, действиеспособное сообщение с точными командами для решения, вместо сырого Docker-ошибки. Благодарность @chriscrosstalk за вклад!
- **System**: кнопка Update для сервиса теперь отключена и отображает "Updating..." во время выполнения обновления, что предотвращает двойные нажатия, которые ранее приводили к ошибкам Docker. Состояние "в процессе" сохраняется, поэтому выдержка страницы во время загрузки многого гигабайта не нарушает процесс. Благодарность @chriscrosstalk за вклад!
- **System Updates**: проверки обновлений больше не падают из-за изображений с более чем 1000 тегами (например, Ollama). URL-адреса пагинации реестра теперь правильно разрешаются, поэтому поток "Проверить обновления" возвращает версии вместо бесконечного молчания — исправлено, что Ollama, казалось бы, зафиксирован на старой версии. Благодарность @chriscrosstalk за вклад!
- **System**: проверки статуса интернета больше не сообщают "Нет подключения к интернету" на сетях, блокирующих или перехватывающих Cloudflare 1.1.1.1. Теперь проверяется параллельно несколько дополнительных хостов, с которыми приложение уже взаимодействует (GitHub и API Project NOMAD), и принимается любой HTTP-ответ как "онлайн". Благодарность @akashsalan за вклад!
- **AI Assistant**: перемещение больших блоков встраивания теперь усекается и повторяется вместо того, чтобы неявно теряться, что могло привести к блокировке GPU и засорению логов (проблема "api/embed for weeks"). Путь отказов совместим с OpenAI и теперь также передаёт параметры контекста и усечения. Благодарность @chriscrosstalk за вклад!
- **AI Assistant**: подсказки чата теперь используют выбранную модель (возврат к самой *маленькой* установленной модели) вместо самой большой. Это предотвращает блокировку страницы чата и ошибку 500 от flagship модели, превышающей доступную видеопамять VRAM. Благодарность @johno10661 за вклад!
- **AI Assistant**: ассистент больше не отказывается "Извините, я не нашёл конкретного контекста относительно X..." когда релевантный материал был на самом деле извлечён. RAG-подсказка теперь считает извлечённый контекст авторитетным источником и тихо переходит к общему знанию, нейтральные метки релевантности, которые заставляли более мелкие модели не доверять правильному контексту, были заменены на нейтральные метки названий источников, и консервативное усиление совпадения заголовков улучшает ранжирование уже извлечённых частей. Благодарность @jakeaturner за вклад!
- **Knowledge Base**: количество встроенных частей для пакетной инъекции ZIM теперь сохраняется точно через продолжения пакетов, вместо отчёта только последней пакетной инъекции. Благодарность @Metbcy за исправление!
- **Knowledge Base**: предупреждение "инъекция может быть приостановлена" (частичная приостановка) больше не срабатывает ложно на ZIM, содержащих много ссылок или PDF, у которых мало встраиваемого текста. Благодарность @chriscrosstalk за вклад!
- **Knowledge Base**: прогресс инъекции ZIM больше не застревает на 99% в мультистраничных архивах (например, iFixit). Прогресс теперь плавно двигается вперёд и сообщает 100% только на действительно последнем пакете. Благодарность @chriscrosstalk за вклад!
- **Content**: установка более новой версии отобранного карты или ZIM теперь удаляет устаревшую файлу из диска, предотвращая накопление "призрачного" контента (возможно сотни гигабайт). Удаление ограничено строгими мерами безопасности — удаляются только отслеживаемые, действительно заменённые и строго более новые файлы в хранилище контента; сideloaded файлы никогда не затрагиваются. Благодарность @chriscrosstalk за вклад!
- **Content**: отобранные ZIM с темой Wikipedia (например, `wikipedia_en_medicine_maxi` из Medicine → Comprehensive) больше не удаляются при перезапуске. Реконсиляция пропускает только один файл, управляемый выбором Wikipedia, совмещённым по точному имени файла. Благодарность @chriscrosstalk за вклад!
- **Maps**: наличие старой и новой копии одного и того же региона карты на диске больше не пустает всю карту. Источники карт теперь дедуплицируются по новейшему файлу на каждый регион, и нерабочие установки восстанавливаются автоматически при следующем загрузке страницы. Благодарность @chriscrosstalk за вклад!
- **Information Library (Kiwix)**: Kiwix теперь восстанавливает недостающую или повреждённую библиотечную файлку при запуске, пересоздавая её из ZIM-файлов на диске, вместо пустой библиотеки и невозможности восстановления. Благодарность @chriscrosstalk за вклад!

- **System**: сбои установки сервиса из-за конфликта порта на хосте (часто из-за существующей установки Ollama на порту 11434) теперь показывают понятное, действиеспособное сообщение с точными командами для решения, вместо сырого Docker-ошибки. Благодарность @chriscrosstalk за вклад!
- **System**: кнопка Update для сервиса теперь отключена и отображает "Updating..." во время выполнения обновления, что предотвращает двойные нажатия, которые ранее приводили к ошибкам Docker. Состояние "в процессе" сохраняется, поэтому выдержка страницы во время загрузки многого гигабайта не нарушает процесс. Благодарность @chriscrosstalk за вклад!
- **System Updates**: проверки обновлений больше не падают из-за изображений с более чем 1,000 тегами (например, Ollama). URL-адреса пагинации реестра теперь правильно разрешаются, поэтому поток "Проверить обновления" возвращает версии вместо молчаливого провала — исправлено, что Ollama, казалось бы, зафиксирован на старой версии. Благодарность @chriscrosstalk за вклад!
- **System**: проверки статуса интернета больше не сообщают "Нет подключения к интернету" на сетях, блокирующих или перехватывающих Cloudflare 1.1.1.1. Теперь проверяется параллельно несколько дополнительных хостов, с которыми приложение уже контактирует (GitHub и Project NOMAD API), и принимается любой HTTP-ответ как "онлайн". Благодарность @akashsalan за вклад!
- **AI Assistant**: перемещение больших блоков встраивания теперь усекается и повторяется вместо того, чтобы быть неявно удалёнными, что могло привести к блокировке GPU и засорению логов (проблема "api/embed for weeks"). Путь отказов совместим с OpenAI и теперь также передаёт параметры контекста и усечения. Благодарность @chriscrosstalk за вклад!
- **AI Assistant**: подсказки чата теперь используют выбранную модель (возврат к самой *маленькой* установленной модели) вместо самой большой. Это предотвращает блокировку страницы чата и ошибку 500 от flagship модели, превышающей доступную видеопамять VRAM. Благодарность @johno10661 за вклад!
- **AI Assistant**: ассистент больше не отказывается "Извините, я не нашёл конкретного контекста относительно X..." когда релевантный материал был извлечён. RAG-подсказка теперь считает извлечённый контекст авторитетным источником и тихо переходит к общему знанию, нейтральные метки релевантности, которые заставляли более мелкие модели не доверять правильному контексту, были заменены на нейтральные метки названий источников, и консервативное усиление совпадения заголовков улучшает ранжирование уже извлечённых частей. Благодарность @jakeaturner за вклад!
- **Knowledge Base**: количество встроенных частей для пакетной инъекции ZIM теперь сохраняется точно через продолжения пакетов, вместо отчёта только последней пакетной инъекции. Благодарность @Metbcy за исправление!
- **Knowledge Base**: предупреждение "инъекция может быть приостановлена" (частичная приостановка) больше не срабатывает ложно на ZIM, содержащих много ссылок или PDF, у которых мало встраиваемого текста. Благодарность @chriscrosstalk за вклад!
- **Knowledge Base**: прогресс инъекции ZIM больше не застревает на 99% в мультистраничных архивах (например, iFixit). Прогресс теперь плавно двигается вперёд и сообщает 100% только на действительно последнем пакете. Благодарность @chriscrosstalk за вклад!
- **Content**: установка более новой версии отобранного карты или ZIM теперь удаляет устаревшую файлу из диска, предотвращая накопление "призрачного" контента (возможно сотни гигабайт). Удаление ограничено строгими мерами безопасности — удаляются только отслеживаемые, действительно заменённые и строго более новые файлы в хранилище контента; сideloaded файлы никогда не затрагиваются. Благодарность @chriscrosstalk за вклад!
- **Content**: отобранные ZIM с темой Wikipedia (например, `wikipedia_en_medicine_maxi` из Medicine → Comprehensive) больше не удаляются при перезапуске. Реконсиляция пропускает только один файл, управляемый выбором Wikipedia, совмещённым по точному имени файла. Благодарность @chriscrosstalk за вклад!
- **Maps**: наличие старой и новой копии одного и того же региона карты на диске больше не пустает всю карту. Источники карт теперь дедуплицируются по новейшему файлу на каждый регион, и уже сломанные установки восстанавливаются автоматически при следующем загрузке страницы. Благодарность @chriscrosstalk за вклад!
- **Information Library (Kiwix)**: Kiwix теперь сам восстанавливает недостающую или повреждённую библиотечную файлку при запуске, пересоздавая её из ZIM-файлов на диске, вместо пустой библиотеки и невозможности восстановления. Благодарность @chriscrosstalk за вклад!
